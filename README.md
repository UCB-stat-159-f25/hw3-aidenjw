This project is for Homework 3 for the Stat 159 class. Using the LOSC Event tutorial, several functions were moved to a newly created ligotools package. This includes a readligo and a utils file, with relavant tests for both. Ligotools is an installable package. The repo is set up to be a MyST repo that builds a page for the LOSC Event tutorial notebook with a Binder link in the build. The website is also deployed to GitHub pages, using GitHub Action to update the website. There is a Makefile containing commands for env, html, and clean.
